# 生成式人工智能交互闭环实验数据

本仓库保存论文《从生成艺术到生成式人工智能：交互闭环中的大众审美重塑》所使用的公开提示词驱动复现实验的**脱敏文字记录**。

## 数据范围

- 30 条公开提示词任务种子
- 16 条研究者生成会话
- 第一轮 18 张结果图，第二轮 14 张，第三轮 9 张
- 31 条提示词版本记录
- 85 条过程事件记录
- 5 个典型案例：`SEED-002`、`SEED-007`、`SEED-017`、`SEED-019`、`SEED-021`
- 1 个平台治理事件：`SEED-020` 的 P1 被安全策略拦截

## 重要边界

1. 本数据记录的是研究者对公开任务的复现、比较和提示词修订过程，不是原作者的真实生成行为，也不代表一般用户的总体行为。
2. 原始工作簿中的嵌入图片、截图和本机文件路径没有上传。原图仅保留公开来源链接，见 `data/task_seed_library.csv` 和 `data/round_comparison.csv`。
3. 公开提示词仅作为研究材料引用，原作者、来源平台及相关权利人的权利不因本仓库而改变。
4. 平台、模型版本和完整交互上下文并非每条记录都齐全，因此本数据适合进行过程性和机制性分析，不适合作为平台性能排名或用户行为总体推断的依据。
5. 部分 CSV 的字段名沿用了原工作簿的历史模板结构；当前公开版本不主张进行严格的跨平台性能比较。

## 文件说明

`data/` 下的 CSV 文件对应原工作簿的各个工作表。字段说明见 [`data_dictionary.md`](data_dictionary.md)，导出来源与校验信息见 [`PROVENANCE.md`](PROVENANCE.md)。

## 使用方式

CSV 文件采用 UTF-8 with BOM 编码，可直接用 Excel、Numbers、LibreOffice 或 Python/R 导入。分析时建议以 `session_registry.csv` 的“会话ID”为基本单位，以 `prompt_versions.csv` 和 `process_events.csv` 还原多轮交互，再用 `case_studies.csv` 对照典型案例。
